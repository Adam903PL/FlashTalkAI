# 📚 FlashTalkAI

**FlashTalkAI** is a learning platform inspired by Quizlet, built with **React + TypeScript**, that combines classic study tools with AI-powered learning support.

It allows users to study with **flashcards**, generate **AI-based tests**, and learn interactively with help from AI. The repository structure also shows both a frontend app and a backend/server part, which suggests a full-stack learning system rather than just a static interface. ([GitHub][1])

---

## 💡 Overview

FlashTalkAI was designed as a smart study app where users can:

* learn with flashcards
* generate tests using AI
* practice knowledge interactively
* use modern web-based learning tools

The project is built mainly in **TypeScript**, with a React/Vite-style frontend structure and a separate `server` directory for backend logic. ([GitHub][1])

---

## 🔑 Core Features

### 🗂️ Flashcards

* Study with classic flashcard-based learning
* Review terms and definitions in an interactive way

### 🤖 AI Test Generation

* Generate quizzes and learning materials with AI
* Turn study content into practice questions automatically

### 🧠 AI-Assisted Learning

* Use AI not only to test knowledge, but also to support the learning process itself
* Makes studying more dynamic than a traditional flashcard app

### 🌐 Full Web Application

The repository includes:

* `src` for the main frontend
* `public` for static assets
* `server` for backend-related logic
* `uploads` for stored content/files
  which indicates a richer app architecture than a simple frontend-only clone. ([GitHub][1])
